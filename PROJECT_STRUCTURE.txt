Quick Reference
===============

To Get Started:
  1. Read: START_HERE.md
  2. Run:  python test_setup.py
  3. Run:  ./run_example.sh

To View Results:
  ./view_results.sh

To Run Custom Benchmark:
  python redis_benchmark.py --data-sizes 64 256 --ratios 1:1

For Help:
  python redis_benchmark.py --help

Typical Workflow
================

1. Flush Database (optional)
   └─> redis-cli FLUSHALL

2. Populate Database
   └─> memtier_benchmark --ratio 1:0

3. Wait (configurable)
   └─> time.sleep(N)

4. Run Benchmark
   └─> memtier_benchmark --ratio X:Y

5. Parse Results
   └─> Extract metrics from JSON

6. Store Results
   └─> Append to results list

7. Repeat for all permutations

8. Generate Reports
   ├─> Save JSON
   ├─> Print text report
   └─> Create visualizations

            - 300 DPI resolution
            - Professional styling

Benefits:
  ✓ Each run is self-contained
  ✓ Easy to compare different runs
  ✓ Simple archiving and cleanup
  ✓ No file conflicts between runs
